# Physical AI (Mobility + Agent)

**차량형 로봇의 강화학습 기반 동적 장애물 회피 및 멀티 로봇 협업 주행 연구**

MuJoCo와 ROS 2 기반 가상환경에서 한백전자 **AutoCAR III G** 차량형 로봇의 근거리 주행 판단을 연구하고, 단일 차량 검증을 거쳐 실물 다중 로봇 협업 주행으로 확장하는 프로젝트입니다.

🔗 [포트폴리오의 프로젝트 상세 설명](https://githaewon.github.io/portfolio-lab/projects/physical-ai-mobility.html)

## 연구 목표

차량형 로봇은 최소 회전 반경과 조향 제약을 지키면서 움직이는 장애물을 만나면 **감속·대기·우회**를 판단하고, 장애물을 피한 뒤 원래 경로로 복귀해야 합니다.

이 프로젝트의 핵심은 이러한 **근거리 판단을 강화학습으로 학습**하고, 기존 제어 방식과 동일한 조건에서 비교·검증하는 것입니다.

> **연구 질문:** 같은 Hybrid A* 전역 경로를 사용할 때, 강화학습(PPO)으로 학습한 근거리 제어는 MPPI와 비교해 이동 장애물을 피한 뒤 얼마나 안정적으로 경로에 복귀해 목적지에 도달할 수 있을까?

- **기준선:** Hybrid A* 전역 경로 + MPPI 근거리 제어
- **비교안:** 동일한 Hybrid A* 전역 경로 + PPO 기반 근거리 회피·경로 복귀
- **주요 평가:** 목표 도달 성공률, 충돌 여부, 경로 복귀 시간, 장애물과의 최소 거리, 조향 변화량, 판단 계산 시간
- **비교 원칙:** 동일한 차량 모델·센서·주행 조건을 사용하고, 학습 및 조정에 사용하지 않은 시험 시나리오로 평가
- **연구 확장:** 단일 차량에서 검증한 판단을 다중 로봇 환경에 적용하고, 중앙 관제 에이전트를 통한 통로 통과 순서·목적지 할당 등 협업 주행 검증

**최종 목표는 AutoCAR III G 실물 차량 3대가 공동 목표를 수행하도록 협업 주행 시스템을 구현·검증하는 것입니다.**

## 연구 단계

1. **시뮬레이션 기반 구축:** MuJoCo 차량 모델 및 ROS 2 연동, 가상 LiDAR·오도메트리·좌표계와 기본 주행 검증
2. **인지·경로 계획:** LiDAR 기반 SLAM 및 위치 추정, 차량 조향 제약을 고려한 Hybrid A* 전역 경로 계획
3. **근거리 제어 비교:** MPPI 기준선 구현, PPO 강화학습 및 동일 조건의 반복 비교 실험
4. **단일 실물 차량 검증:** AutoCAR III G 연동, 안전 제어 및 시뮬레이션-실물 성능 차이 확인
5. **멀티에이전트 확장:** 다중 차량의 독립 주행과 중앙 관제 기반 협업 주행 비교, 최종 실물 3대 검증
